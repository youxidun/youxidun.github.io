接入说明
多平台 SDK
集成指南

基于正式版本 v3 接入文档整理，覆盖原生平台、Unity、Cocos Creator、Flutter 与 UniApp。开发者只需完成 SDK 初始化、获取本地端口、通过 127.0.0.1 转发访问真实后端，并在退出时释放资源。

iOS macOS Android Windows Unity Cocos Creator Flutter UniApp

接入核心模型

启动防护服务后，根据规则名获取本地端口，业务请求改为访问本机地址，由 SDK 安全隧道转发至真实后端服务。

启动startService(pid, key)
端口getLocalhostPort(rule)
访问http://127.0.0.1:{port}
释放stopService()
Integration Flow

四步完成基础接入

不同平台的工程配置不同，但运行时调用模型保持一致，方便统一业务改造和排查。

1. 引入 SDK

将 framework、dylib、aar、dll、unitypackage 或插件目录加入项目。

2. 启动服务

传入项目 ID 与授权密钥，依据回调或返回值判断初始化结果。

3. 获取端口

通过规则名获取 localhost 端口，并将业务请求改为本地访问。

4. 退出释放

应用退出前调用停止方法，释放防护服务占用的资源。

Native Platforms

原生平台接入

覆盖 iOS、macOS、Android 与 Windows，适合原生客户端或需要直接绑定底层库的项目。

01

iOS

添加 netshield.framework，配置 framework 搜索路径和 header 搜索路径，头文件为 LibNetshield.h。

工程配置

  • 添加 netshield.framework 文件。
  • framework 搜索路径指向 framework 所在目录。
  • header 搜索路径使用 netshield.framework 全路径并追加 /Headers。
#import <LibNetshield.h>

[LibNetshield startService:@"123"
                       key:@"12345678901234567890"
         completionHandler:^(BOOL success, NSString *errMessage, NSString *clientIP) {
  if (success) {
    NSLog(@"SDK start success,clientIP:%@", clientIP);
  } else {
    NSLog(@"SDK start failed, errMessage:%@", errMessage);
  }
}];

int localPort = [LibNetshield getLocalhostPort:@"test;10001"];
NSString *url = [NSString stringWithFormat:@"http://127.0.0.1:%d", localPort];

[LibNetshield stopService];
02

macOS

添加 libnetshield.dylib 并设置链接搜索路径。C++ 与 Objective-C 混编时需将 .m 后缀改为 .mm。

接口

  • startNetshieldService(pid, key, completionHandler)
  • getLocalhostPort(rule)
  • stopNetshieldService()
extern void startNetshieldService(const char *, const char *, void (*)(int, const char *, const char *));
extern int getLocalhostPort(const char *);
extern void stopNetshieldService();

startNetshieldService("123", "12345678901234567890",
  [](int startResult, const char *errMessage, const char *clientIP) {
    if (startResult == 0) {
      NSLog(@"SDK started success,clientIP:%s", clientIP);
    } else {
      NSLog(@"SDK started failed, errMsg:%s", errMessage);
    }
  });

int localhostPort = getLocalhostPort("240.0.0.2;80");
NSString *localhostUrl = [NSString stringWithFormat:@"http://127.0.0.1:%d", localhostPort];

stopNetshieldService();
03

Android

在 app/build.gradle 添加 aar 路径，并将 minSdkVersion 调整为 21 或以上。类文件为 com.netshield.Netshield。

接口

  • Netshield.startService(pid, key)
  • Netshield.getClientIP()
  • Netshield.getErrMessage()
  • Netshield.getLocalhostPort(rule)
  • Netshield.stopService()
int startResult = Netshield.startService("123", "12345678901234567890");
if (startResult == 0) {
  String clientIP = Netshield.getClientIP();
  Log.d("SDK", "SDK start success,clientIP:" + clientIP);
} else {
  String errMessage = Netshield.getErrMessage();
  Log.e("SDK", "SDK start failed,errMessage:" + errMessage);
}

int localPort = Netshield.getLocalhostPort("test;10001");
String url = String.format("http://127.0.0.1:%d", localPort);

Netshield.stopService();
04

Windows

将 netshield.dll 放置到 exe 同级目录，可动态加载 DLL 并获取 start、port、stop 等函数地址。

部署重点

  • netshield.dll 必须随 exe 正确发布。
  • 启动成功返回 0，失败返回 -1。
  • 如果进程无法退出，在 main 函数结束前调用 stopNetshieldService。
HMODULE netshieldDll = LoadLibrary(L"netshield.dll");
auto startNetshieldService =
  reinterpret_cast<int(__cdecl *)(const char *, const char *)>(
    GetProcAddress(netshieldDll, "startNetshieldService"));
auto getLocalhostPort =
  reinterpret_cast<int(__cdecl *)(const char *)>(
    GetProcAddress(netshieldDll, "getLocalhostPort"));
auto stopNetshieldService =
  reinterpret_cast<void(__cdecl *)()>(
    GetProcAddress(netshieldDll, "stopNetshieldService"));

int startResult = startNetshieldService("123", "12345678901234567890");
int localPort = getLocalhostPort("test;10001");

char url[1024];
snprintf(url, sizeof(url), "http://127.0.0.1:%d", localPort);

stopNetshieldService();
Game Engines

Unity 与 Cocos Creator 接入

面向游戏项目，可通过插件包、桥接文件与平台库完成跨平台防护能力接入。

05

Unity

Unity 支持 unitypackage 或 NetshieldPlugins 插件包两种方式，推荐使用 unitypackage。

工程配置

  • 拖动 Netshield.unitypackage 到 Unity 中。
  • 或将 NetshieldPlugins 放到 Assets 目录下。
  • iOS framework 需设置为 Embedded Binaries。
Netshield4Unity.GetInstance().StartService(
  "123",
  "12345678901234567890",
  (startResult, errMessage, clientIP) => {
    if (startResult == 0) {
      Debug.Log($"SDK start success,clientIP:{clientIP}");
    } else {
      Debug.LogError($"SDK start failed, errMessage:{errMessage}");
    }
  });

int localPort =
  Netshield.Netshield4Unity.GetInstance().GetLocalhostPort("test;10001");
var url = "http://127.0.0.1:" + localPort;

Netshield4Unity.GetInstance().StopService();
06

Cocos Creator

拷贝 Netshield.js 到脚本目录，并按 Android、iOS/macOS、Windows 对应放置 aar、framework、dylib、dll 与桥接文件。

库结构

  • netshield/android/netshield-release.aar
  • netshield/ios_mac/ios/netshield.framework
  • netshield/ios_mac/mac/libnetshield.dylib
  • netshield/windows/netshield.dll
async onStartSDK() {
  const startResult = await Netshield.start("123", "1231231231231231231231");
  if (startResult.startResult === 0) {
    console.log("SDK start success,clientIP:" + startResult.clientIP);
  } else {
    this.appendLog("SDK start failed, errMessage:" + startResult.errMessage);
  }
}

onRequestPage() {
  const localhostPort = Netshield.getLocalhostPort("240.0.0.2;80");
  let url = "http://127.0.0.1:" + localhostPort;
  console.log("访问页面: " + url);
}

onStopSDK() {
  Netshield.stop();
}
Cross-Platform Frameworks

Flutter 与 UniApp 接入

跨端框架通过插件方式接入，业务层仍遵循启动服务、获取端口、本地访问、退出释放的统一模型。

07

Flutter

SDK 以 Flutter plugin 形式提供。Windows 11 需要打开开发者模式，以允许 Flutter 插件的 symlink 特性。

添加依赖

dependencies:
  netshield4flutter:
    path: ../path/to/your/netshield4flutter
import 'package:netshield4flutter/netshield4flutter.dart';

final _netshield4flutterPlugin = Netshield4flutter();

final startResult = await _netshield4flutterPlugin.startService(
  '123',
  '1231231231231231231231',
);

if (startResult.isSuccess) {
  _addLog('SDK start success,clientIP:${startResult.clientIP}');
} else {
  _addLog('SDK start failed, errMessage:${startResult.errMessage}');
}

final localhostPort =
  await _netshield4flutterPlugin.getLocalhostPort("240.0.0.2;80");
String url = "http://127.0.0.1:$localhostPort";

await _netshield4flutterPlugin.stopService();
08

UniApp

支持 uts 插件与原生插件两种方式。uts 插件放到 uni_modules，原生插件放到 nativeplugins 并在 manifest.json 中启用。

插件方式

  • uts 插件：从 @/uni_modules/dev-netshield 引入方法。
  • 原生插件：通过 uni.requireNativePlugin('netshieldNativePlugin') 调用。
import {
  startNetshieldService,
  stopNetshieldService,
  getLocalhostPort
} from "@/uni_modules/dev-netshield";

startNetshieldService("123", "1231231231231231231231",
  (startResult: Array<string>) => {
    if ("0" == startResult[0]) {
      this.addLog("SDK start success,clientIP:" + startResult[2]);
    } else {
      this.addLog("SDK start failed, errMessage:" + startResult[1]);
    }
  });

const localhostPort = getLocalhostPort("240.0.0.2;80");
let url = "http://127.0.0.1:" + localhostPort;

stopNetshieldService();
Checklist

上线前注意事项

以下内容来自正式接入文档的注意事项部分，建议在联调和发布前逐项确认。

初始化时机

应用启动后尽早调用初始化方法，避免业务请求先于防护服务建立。

错误处理

iOS/macOS 通过 completionHandler 判断结果，其他平台通过返回值判断，0 表示成功。

资源释放

应用退出时调用 stopNetshieldService 或对应 stop 方法，释放 SDK 资源。

动态库依赖

Windows 需正确部署 netshield.dll；iOS/macOS 的 framework 必须配置为 Embed 模式，否则可能运行时崩溃。

接入联调或技术支持

如需获取 SDK 包、项目 ID、授权密钥、规则名配置或私有化部署协助，请联系技术支持。
